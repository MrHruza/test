Jak se připojit na server?

Vítej v návodu pro připojení na MystiLand! Ať už hraješ na počítači přes klasickou Java edici nebo na telefonu/konzoli přes Bedrock, zde najdeš vše potřebné. Nejdříve si můžeš pustit naše ukázkové video ze serveru.

Minecraft Java Edition (PC / Mac / Linux)

▼

1. Zapni svou hru Minecraft Java Edition (doporučujeme verze od 1.20 výše).

2. V hlavní nabídce klikni na Multiplayer (Hra pro více hráčů).

3. Klikni dole na tlačítko Přidat server (Add Server).

4. Do kolonky Adresa serveru zadej následující text:

play.mystiland.eu

5. Potvrď tlačítko Hotovo a můžeš se připojit dvojklikem na server v seznamu!

Minecraft Bedrock Edition (Mobily, Tablety, Konzole)

▼

1. Spusť Minecraft a v menu klikni na tlačítko Hrát (Play).

2. Přepni se v záložkách nahoru na sekci Server.

3. Sjeď úplně dolů a klikni na Přidat server (Add Server).

4. Vyplň údaje podle údajů níže:

  • • Název serveru: MystiLand
  • • Adresa serveru: play.mystiland.eu
  • • Port: 19132 (výchozí)
IP: play.mystiland.eu | Port: 19132

5. Klikni na Uložit a následně se připoj do hry.
