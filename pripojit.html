Jak se připojit na server?

Vítej v oficiálním návodu pro připojení na MystiLand! Ať už hraješ na počítači přes Java edici nebo na telefonu/tabletu přes Bedrock, zde najdeš vše potřebné pro bezproblémový vstup do hry. Nejdříve si můžeš pustit naše představení serveru.

Minecraft Java Edition (PC / Mac / Linux)

▼

1. Spusť svou hru Minecraft Java Edition (doporučujeme verze od 1.20 výše).

2. V hlavním menu klikni na položku Multiplayer (Hra pro více hráčů).

3. Dole klikni na tlačítko Přidat server (Add Server).

4. Do políčka Adresa serveru vlož následující text:

play.mystiland.eu

5. Potvrď tlačítko Hotovo a můžeš se rovnou připojit dvojklikem do hry!

Minecraft Bedrock Edition (Mobily a Tablety)

▼

1. Spusť Minecraft na svém mobilním zařízení nebo tabletu a klikni na Hrát (Play).

2. Nahoře se přepni do záložky Server.

3. Sjeď úplně dolů a klikni na tlačítko Přidat server (Add Server).

4. Vyplň údaje podle údajů níže:

  • • Název serveru: MystiLand
  • • Adresa serveru: play.mystiland.eu
  • • Port: 19132 (výchozí)
play.mystiland.eu : 19132

5. Klikni na Uložit a připoj se na server.
